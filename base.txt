# System Requirements Specification (SRS)

## Project Title

**Dilini Motors – Jeep Modification Garage Website**

## 1. Introduction

### 1.1 Purpose

This document defines the functional, non-functional, and design requirements for the Dilini Motors website. The system will serve as a modern, visually engaging, and informative web presence for Dilini Motors, a Jeep Modification Garage based in Nittambuwa, Sri Lanka. The website aims to attract customers, showcase expertise, and simplify customer communication.

### 1.2 Scope

The website will:

* Present Dilini Motors’ services, expertise, and portfolio
* Enable customers to easily contact the garage
* Showcase real-world projects through a gallery
* Improve online visibility via SEO and Google Business integration
* Use modern UI/UX principles with animations and interactive visuals

### 1.3 Target Audience

* Jeep owners and off-road enthusiasts in Sri Lanka
* Customers seeking custom vehicle modifications
* Potential partners and automotive communities

---

## 2. Overall Description

### 2.1 Product Perspective

The system is a responsive, single-domain marketing and portfolio website. It may be implemented as a static or dynamic web application using modern frontend frameworks or CMS platforms (e.g., WordPress, React-based stack, or Webflow).

### 2.2 User Classes

* **General Visitors**: Browse services, gallery, and company details
* **Potential Customers**: Contact the garage, request services, upload vehicle photos
* **Admin (Optional – Future)**: Update content, gallery, testimonials

### 2.3 Operating Environment

* Web browsers (Chrome, Firefox, Safari, Edge)
* Desktop, tablet, and mobile devices
* Deployed on shared or cloud hosting

## 9. Design System

### 9.1 Design Principles

* Minimal, bold, and mechanical
* High contrast with controlled motion
* Content-first, animation-enhanced

### 9.2 Color Palette

* Primary Black: #0B0B0B
* Dark Gray: #1F1F1F
* Accent Orange: #FF6A00
* Light Gray: #E5E5E5
* White: #FFFFFF

### 9.3 Typography

* Headings: Bebas Neue / Oswald
* Body: Inter / Roboto
* Emphasis: Semi-bold weights only

### 9.4 Spacing & Layout

* 8px spacing system
* Max-width containers (1200–1440px)
* Generous vertical spacing

### 9.5 Motion Guidelines

* Entrance animations: Fade + Slide (100–300ms)
* Hover animations: Scale (1.03), shadow depth
* Scroll animations: Triggered once per section
* Avoid excessive motion on mobile

### 9.6 3D & Interactive Elements

* Spline used sparingly for hero and section backgrounds
* Low-poly or industrial-style 3D assets
* Lottie animations for service icons

## 10. Frontend Technical Stack (Recommended)

* **Framework:** React + Vite
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion, GSAP
* **3D:** Spline Embed
* **Icons:** Lucide / Heroicons
* **Deployment:** Netlify / Vercel
